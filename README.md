# zenn

Zennの記事と本を管理するリポジトリです。パッケージ管理にはpnpmを使用します。

## 必要な環境

- Node.js 22以降
- pnpm 11.15.1

`packageManager` フィールドでpnpmのバージョンを固定しています。Corepackを利用する場合は、あらかじめ有効化してください。

## セットアップ

```sh
pnpm install --frozen-lockfile
```

依存パッケージのインストールスクリプトは無効です。また、公開から24時間が経過していないバージョンや、以前より信頼情報が弱くなったバージョンは解決しません。

## 確認

```sh
pnpm check
```

このコマンドは既知の脆弱性を監査し、Zennの記事を解析します。ローカルプレビューは `pnpm preview` で起動できます。
