## 関数宣言・関数式・即時関数・アロー関数・コールバック・高階関数・async関数まで

JavaScriptを書くうえで、関数は避けて通れません。

関数は、処理をひとまとまりにして、必要なタイミングで呼び出せるようにする仕組みです。

```js
function greet() {
  console.log("こんにちは");
}

greet();
```

このような基本的な関数だけでなく、JavaScriptにはさまざまな関数の書き方があります。

たとえば、次のようなものがあります。

```js
function greet() {
  console.log("こんにちは");
}

const greet = function () {
  console.log("こんにちは");
};

const greet = () => {
  console.log("こんにちは");
};

(() => {
  console.log("すぐに実行されます");
})();
```

どれも関数ですが、それぞれ特徴や使いどころが違います。

この記事では、JavaScriptの関数の種類を整理しながら、使いどころや用途をわかりやすく解説します。

---

# 関数とは

関数とは、特定の処理をまとめて、あとから呼び出せるようにしたものです。

たとえば、次のような処理があるとします。

```js
console.log("おはようございます");
console.log("今日も頑張りましょう");
```

この処理を何度も使いたい場合、毎回同じコードを書くのは面倒です。

そこで、関数にまとめます。

```js
function sayMorningMessage() {
  console.log("おはようございます");
  console.log("今日も頑張りましょう");
}

sayMorningMessage();
```

関数にすることで、次のようなメリットがあります。

* 同じ処理を何度も使い回せる
* 処理に名前を付けられる
* コードの見通しが良くなる
* 修正箇所を減らせる
* 処理を部品として分けられる

JavaScriptでは、関数はただの処理のまとまりではありません。

関数を変数に入れたり、別の関数に渡したり、関数から関数を返したりできます。

この性質が、JavaScriptの関数を理解するうえでとても重要です。

---

# 1. 関数宣言

まず基本になるのが、関数宣言です。

```js
function greet() {
  console.log("こんにちは");
}

greet();
```

`function` キーワードを使って、名前付きの関数を定義します。

```js
function 関数名() {
  処理;
}
```

## 引数を受け取る関数

関数には、外から値を渡せます。

```js
function greet(name) {
  console.log(`${name}さん、こんにちは`);
}

greet("田中");
greet("佐藤");
```

出力結果です。

```txt
田中さん、こんにちは
佐藤さん、こんにちは
```

この `name` のように、関数が受け取る値を「引数」と呼びます。

## 戻り値を返す関数

関数は、処理結果を返すこともできます。

```js
function add(a, b) {
  return a + b;
}

const result = add(3, 5);

console.log(result);
```

出力結果です。

```txt
8
```

`return` を使うと、関数の外に値を返せます。

```js
function isAdult(age) {
  return age >= 20;
}

console.log(isAdult(25));
console.log(isAdult(18));
```

```txt
true
false
```

## 関数宣言は定義前に呼び出せる

関数宣言の大きな特徴は、定義より前に呼び出せることです。

```js
greet();

function greet() {
  console.log("こんにちは");
}
```

このコードは動きます。

JavaScriptでは、関数宣言が実行前にメモリ上へ登録されるためです。

この仕組みを「巻き上げ」と呼びます。

## 関数宣言の使いどころ

関数宣言は、名前のある処理をわかりやすく定義したいときに向いています。

```js
function validateEmail(email) {
  return email.includes("@");
}

function calculateTotalPrice(price, quantity) {
  return price * quantity;
}

function formatUserName(firstName, lastName) {
  return `${lastName} ${firstName}`;
}
```

特に、次のような処理に向いています。

* 汎用的に使う処理
* 名前を付けて意味を明確にしたい処理
* ファイル内のどこからでも呼び出したい処理
* 初心者にも読みやすくしたい処理

関数宣言は、もっとも基本的で読みやすい関数の書き方です。

# 2. 関数式

関数式は、関数を変数に代入する書き方です。

```js
const greet = function () {
  console.log("こんにちは");
};

greet();
```

関数宣言と似ていますが、こちらは「関数を作って、それを変数に入れている」と考えるとわかりやすいです。

```js
const 関数名 = function () {
  処理;
};
```

## 関数を値として扱う

JavaScriptでは、関数は値として扱えます。

```js
const message = "こんにちは";

const greet = function () {
  console.log("こんにちは");
};
```

`message` には文字列が入っています。

`greet` には関数が入っています。

つまり、JavaScriptでは、文字列や数値と同じように関数を変数へ代入できます。

## 関数式は定義前に呼び出せない

関数式は、定義より前に呼び出せません。

```js
greet();

const greet = function () {
  console.log("こんにちは");
};
```

これはエラーになります。

`const greet` がまだ初期化されていない状態で呼び出しているためです。

関数宣言との大きな違いです。

## 名前付き関数式

関数式には名前を付けることもできます。

```js
const greet = function greetUser() {
  console.log("こんにちは");
};
```

ただし、実務では次のような無名関数の形もよく使われます。

```js
const greet = function () {
  console.log("こんにちは");
};
```

## 関数式の使いどころ

関数式は、関数を値として扱いたいときに向いています。

```js
const validate = function (value) {
  return value.length > 0;
};

console.log(validate("hello"));
```

また、条件によって使う関数を切り替えることもできます。

```js
const mode = "admin";

const getMessage =
  mode === "admin"
    ? function () {
        return "管理者です";
      }
    : function () {
        return "一般ユーザーです";
      };

console.log(getMessage());
```

関数式は、次のような場面で使いやすいです。

* 関数を変数として扱いたい
* 関数をオブジェクトに入れたい
* 関数を引数として渡したい
* 条件によって関数を切り替えたい

# 3. 即時関数

即時関数は、定義した直後にすぐ実行される関数です。

英語では IIFE と呼ばれます。

IIFE は、Immediately Invoked Function Expression の略です。

```js
(function () {
  console.log("すぐに実行されます");
})();
```

または、アロー関数でも書けます。

```js
(() => {
  console.log("すぐに実行されます");
})();
```

## 即時関数の基本形

即時関数は、次のような形で書きます。

```js
(function () {
  処理;
})();
```

ポイントは、関数全体を `()` で囲んでいることです。

```js
(function () {
  console.log("初期化処理");
})();
```

関数を定義してから、最後の `()` でその関数をすぐに呼び出しています。

## なぜ `()` で囲むのか

次のようなコードはエラーになります。

```js
function () {
  console.log("実行");
}();
```

通常の関数宣言には関数名が必要です。

また、JavaScriptはこれを関数式ではなく、関数宣言として解釈しようとします。

そのため、即時関数では関数を `()` で囲み、関数式として扱わせます。

```js
(function () {
  console.log("実行");
})();
```

これにより、「関数をその場で作って、その場で実行する」という書き方になります。

## 即時関数の用途

即時関数は、主に次のような用途で使われます。

* 一度だけ実行したい処理を書く
* 変数のスコープを閉じ込める
* 初期化処理をまとめる
* グローバル汚染を防ぐ
* 昔のJavaScriptでモジュールのように使う

## 一度だけ実行したい処理

ページ読み込み時に一度だけ実行したい処理がある場合、即時関数が使えます。

```js
(() => {
  console.log("アプリの初期化処理を実行します");

  const appName = "Sample App";
  const version = "1.0.0";

  console.log(`${appName} v${version}`);
})();
```

この関数は、定義された直後に一度だけ実行されます。

あとから再利用する必要がない処理に向いています。

## 変数のスコープを閉じ込める

即時関数の大きな役割は、変数のスコープを閉じ込めることです。

```js
(function () {
  const message = "この中だけで使う変数です";

  console.log(message);
})();

console.log(message);
```

最後の `console.log(message)` はエラーになります。

`message` は即時関数の中で定義された変数なので、外から参照できません。

このように、即時関数を使うと、外側に余計な変数を出さずに済みます。

## グローバル汚染を防ぐ

JavaScriptでは、グローバルスコープに変数を増やしすぎると、名前の衝突が起きやすくなります。

```js
const count = 10;
const userName = "田中";
const config = {};
```

小さいコードでは問題になりにくいですが、ファイルが増えると、同じ名前の変数が衝突する可能性があります。

即時関数を使うと、変数を関数の中に閉じ込められます。

```js
(function () {
  const count = 10;
  const userName = "田中";
  const config = {};

  console.log(count, userName, config);
})();
```

この場合、`count`、`userName`、`config` は即時関数の外には出ません。

## 昔のJavaScriptではよく使われていた

現在のJavaScriptでは、`let`、`const`、ES Modules などがあるため、即時関数の出番は以前より少なくなりました。

```js
// 現在はモジュールで分けることが多い
import { fetchUsers } from "./api.js";
```

ただし、即時関数は今でも次のような場面で見かけます。

* 古いJavaScriptコード
* ライブラリの内部実装
* ブラウザで直接動かす小さなスクリプト
* 初期化処理を閉じ込めたい場合
* ブックマークレット

## 即時関数の使いどころ

即時関数は、再利用しない処理をその場で実行したいときに使います。

```js
(() => {
  const theme = localStorage.getItem("theme") || "light";

  document.body.dataset.theme = theme;
})();
```

この処理は、テーマ設定を読み込んで画面に反映する初期化処理です。

何度も呼び出す必要がないため、即時関数に向いています。

## 即時関数を使うときの注意点

即時関数は便利ですが、使いすぎるとコードが読みにくくなる場合があります。

```js
(() => {
  (() => {
    (() => {
      console.log("深すぎる即時関数");
    })();
  })();
})();
```

このようにネストが深くなると、処理の流れがわかりにくくなります。

現在の実務では、次のように判断するとよいです。

* 一度だけ実行する初期化処理なら使ってもよい
* 変数を外に出したくない小さな処理なら使ってもよい
* 再利用する処理なら普通の関数にする
* 大きな処理ならモジュールに分ける

# 4. アロー関数

アロー関数は、ES6から追加された関数の書き方です。

```js
const greet = () => {
  console.log("こんにちは");
};

greet();
```

`function` キーワードを使わず、`=>` を使って書きます。

```js
const 関数名 = () => {
  処理;
};
```

## 引数がある場合

```js
const greet = (name) => {
  console.log(`${name}さん、こんにちは`);
};

greet("田中");
```

引数が1つだけの場合、丸括弧を省略できます。

```js
const greet = name => {
  console.log(`${name}さん、こんにちは`);
};
```

ただし、実務では可読性のために丸括弧を付けることも多いです。

```js
const greet = (name) => {
  console.log(`${name}さん、こんにちは`);
};
```

## 1行で return する場合

アロー関数では、処理が1行だけの場合、`return` と `{}` を省略できます。

```js
const add = (a, b) => {
  return a + b;
};
```

これは次のように書けます。

```js
const add = (a, b) => a + b;
```

配列操作では、この書き方がよく使われます。

```js
const numbers = [1, 2, 3];

const doubled = numbers.map((number) => number * 2);

console.log(doubled);
```

出力結果です。

```txt
[2, 4, 6]
```

## オブジェクトを返す場合の注意

アロー関数でオブジェクトをそのまま返す場合は、丸括弧で囲む必要があります。

```js
const createUser = (name) => ({
  name: name,
  role: "user",
});

console.log(createUser("田中"));
```

次のように書くと、期待通りにオブジェクトが返りません。

```js
const createUser = (name) => {
  name: name;
};
```

`{}` がオブジェクトではなく、関数の処理ブロックとして解釈されるためです。

## アロー関数の特徴

アロー関数の重要な特徴は、自分自身の `this` を持たないことです。

通常の関数では、呼び出され方によって `this` が変わります。

一方で、アロー関数の `this` は外側のスコープの `this` を参照します。

この違いは、オブジェクトのメソッドを書くときに重要になります。

## アロー関数の使いどころ

アロー関数は、短い処理を書くときに便利です。

特に、配列メソッドとの相性が良いです。

```js
const users = [
  { id: 1, name: "田中", age: 20 },
  { id: 2, name: "佐藤", age: 17 },
  { id: 3, name: "鈴木", age: 25 },
];

const adults = users.filter((user) => user.age >= 20);

console.log(adults);
```

イベント処理でもよく使われます。

```js
button.addEventListener("click", () => {
  console.log("クリックされました");
});
```

アロー関数は、次のような場面に向いています。

* 短い処理を書く
* コールバック関数を書く
* `map` / `filter` / `reduce` などで使う
* 外側の `this` を使いたい処理を書く

ただし、すべての関数をアロー関数にすればよいわけではありません。

特に、`this` を使うオブジェクトのメソッドでは注意が必要です。

# 5. メソッド

オブジェクトの中に定義された関数を、メソッドと呼びます。

```js
const user = {
  name: "田中",
  greet: function () {
    console.log("こんにちは");
  },
};

user.greet();
```

この `greet` がメソッドです。

## メソッドの省略記法

オブジェクトのメソッドは、次のように短く書けます。

```js
const user = {
  name: "田中",
  greet() {
    console.log("こんにちは");
  },
};

user.greet();
```

実務では、この省略記法がよく使われます。

## `this` を使うメソッド

メソッドでは、`this` を使って同じオブジェクト内の値を参照できます。

```js
const user = {
  name: "田中",
  greet() {
    console.log(`${this.name}さん、こんにちは`);
  },
};

user.greet();
```

出力結果です。

```txt
田中さん、こんにちは
```

この場合、`this` は `user` オブジェクトを指します。

## メソッドでアロー関数を使う注意点

次のように、メソッドをアロー関数で書くと注意が必要です。

```js
const user = {
  name: "田中",
  greet: () => {
    console.log(`${this.name}さん、こんにちは`);
  },
};

user.greet();
```

この場合、`this` は `user` を指しません。

アロー関数は自分自身の `this` を持たないためです。

そのため、オブジェクトのメソッドで `this` を使う場合は、通常の関数か省略記法を使う方が安全です。

```js
const user = {
  name: "田中",
  greet() {
    console.log(`${this.name}さん、こんにちは`);
  },
};
```

## メソッドの使いどころ

メソッドは、データと処理をセットで管理したいときに使います。

```js
const cart = {
  items: [],
  addItem(item) {
    this.items.push(item);
  },
  getTotalCount() {
    return this.items.length;
  },
};

cart.addItem("りんご");
cart.addItem("みかん");

console.log(cart.getTotalCount());
```

オブジェクトが持つデータに対して、関連する処理をまとめたい場合に便利です。

# 6. コールバック関数

コールバック関数とは、他の関数に渡される関数のことです。

```js
function execute(callback) {
  callback();
}

execute(function () {
  console.log("処理を実行しました");
});
```

この場合、`execute` に渡している関数がコールバック関数です。

## アロー関数で書くコールバック

コールバック関数は、アロー関数で書かれることが多いです。

```js
function execute(callback) {
  callback();
}

execute(() => {
  console.log("処理を実行しました");
});
```

## 配列メソッドで使うコールバック

JavaScriptでは、配列メソッドでコールバック関数をよく使います。

```js
const numbers = [1, 2, 3];

const doubled = numbers.map((number) => {
  return number * 2;
});

console.log(doubled);
```

`map` に渡している関数がコールバック関数です。

短く書くと次のようになります。

```js
const doubled = numbers.map((number) => number * 2);
```

## イベント処理で使うコールバック

イベント処理でも、コールバック関数はよく使われます。

```js
button.addEventListener("click", () => {
  console.log("クリックされました");
});
```

`addEventListener` の第2引数に渡している関数がコールバック関数です。

クリックされたタイミングで、この関数が呼び出されます。

## 非同期処理で使うコールバック

昔のJavaScriptでは、非同期処理でもコールバック関数がよく使われていました。

```js
setTimeout(() => {
  console.log("1秒後に実行されます");
}, 1000);
```

`setTimeout` に渡している関数もコールバック関数です。

## コールバック関数の使いどころ

コールバック関数は、「あとで実行してほしい処理」を渡したいときに使います。

主な用途は次の通りです。

* イベントが発生したときの処理
* 配列の各要素に対する処理
* 非同期処理が終わったあとの処理
* 共通処理の一部だけ差し替えたい場合

コールバック関数は、JavaScriptらしい書き方の中心にある考え方です。

# 7. 高階関数

高階関数とは、関数を受け取る、または関数を返す関数のことです。

JavaScriptでは関数を値として扱えるため、高階関数を作れます。

## 関数を受け取る高階関数

```js
function executeTwice(callback) {
  callback();
  callback();
}

executeTwice(() => {
  console.log("実行");
});
```

出力結果です。

```txt
実行
実行
```

`executeTwice` は関数を引数として受け取っているため、高階関数です。

## 関数を返す高階関数

```js
function createMultiplier(multiplier) {
  return function (number) {
    return number * multiplier;
  };
}

const double = createMultiplier(2);
const triple = createMultiplier(3);

console.log(double(10));
console.log(triple(10));
```

出力結果です。

```txt
20
30
```

このように、関数を作って返すこともできます。

## アロー関数で書く

同じ処理をアロー関数で書くと、次のようになります。

```js
const createMultiplier = (multiplier) => {
  return (number) => {
    return number * multiplier;
  };
};
```

さらに短くすると、次のように書けます。

```js
const createMultiplier = (multiplier) => (number) => number * multiplier;
```

ただし、短くしすぎると読みにくくなることもあります。

初心者向けの記事やチーム開発では、無理に短くしすぎない方が安全です。

## 高階関数の使いどころ

高階関数は、処理の一部を外から差し替えたいときに便利です。

```js
function filterUsers(users, condition) {
  const result = [];

  for (const user of users) {
    if (condition(user)) {
      result.push(user);
    }
  }

  return result;
}

const users = [
  { name: "田中", age: 20 },
  { name: "佐藤", age: 17 },
  { name: "鈴木", age: 25 },
];

const adults = filterUsers(users, (user) => user.age >= 20);

console.log(adults);
```

この例では、`condition` に渡す関数を変えることで、絞り込み条件を自由に変えられます。

高階関数は、次のような場面で使われます。

* 共通処理を作りたい
* 条件や処理だけを外から差し替えたい
* 配列操作をシンプルに書きたい
* 関数を部品として組み合わせたい

`map`、`filter`、`reduce` も高階関数です。

```js
const numbers = [1, 2, 3, 4, 5];

const result = numbers
  .filter((number) => number % 2 === 1)
  .map((number) => number * 2);

console.log(result);
```

出力結果です。

```txt
[2, 6, 10]
```

# 8. async関数

`async` 関数は、非同期処理を書くための関数です。

```js
async function fetchUser() {
  const response = await fetch("/api/user");
  const user = await response.json();

  return user;
}
```

`async` を付けると、その関数の中で `await` が使えるようになります。

## Promiseを返す

`async` 関数は、必ず Promise を返します。

```js
async function getNumber() {
  return 10;
}

const result = getNumber();

console.log(result);
```

この場合、`10` そのものではなく、Promise が返ります。

値を取り出すには `await` を使います。

```js
async function getNumber() {
  return 10;
}

const result = await getNumber();

console.log(result);
```

## API通信で使う

`async` 関数は、API通信でよく使われます。

```js
async function fetchUsers() {
  const response = await fetch("/api/users");

  if (!response.ok) {
    throw new Error("ユーザー一覧の取得に失敗しました");
  }

  const users = await response.json();

  return users;
}
```

呼び出す側です。

```js
try {
  const users = await fetchUsers();

  console.log(users);
} catch (error) {
  console.error(error);
}
```

## async関数の使いどころ

`async` 関数は、非同期処理を読みやすく書きたいときに使います。

主な用途は次の通りです。

* API通信
* ファイル読み込み
* データベース処理
* タイマー処理
* Promiseを返す処理の制御

Promiseの `.then()` を使った書き方より、処理の流れを上から下に読みやすいのが特徴です。

```js
fetch("/api/users")
  .then((response) => response.json())
  .then((users) => {
    console.log(users);
  });
```

これを `async` / `await` で書くと、次のようになります。

```js
const response = await fetch("/api/users");
const users = await response.json();

console.log(users);
```

# 9. ジェネレーター関数

ジェネレーター関数は、処理を途中で止めたり、再開したりできる特殊な関数です。

```js
function* generateNumbers() {
  yield 1;
  yield 2;
  yield 3;
}

const generator = generateNumbers();

console.log(generator.next());
console.log(generator.next());
console.log(generator.next());
```

出力結果です。

```txt
{ value: 1, done: false }
{ value: 2, done: false }
{ value: 3, done: false }
```

通常の関数は、一度呼び出すと最後まで実行されます。

しかし、ジェネレーター関数は `yield` の位置で一時停止できます。

## ジェネレーター関数の特徴

ジェネレーター関数は、`function*` を使って定義します。

```js
function* 関数名() {
  yield 値;
}
```

呼び出すと、すぐに処理が実行されるのではなく、ジェネレーターオブジェクトが返ります。

```js
const generator = generateNumbers();
```

実際に次の値を取得するには、`next()` を呼びます。

```js
generator.next();
```

## ジェネレーター関数の使いどころ

ジェネレーター関数は、次のような場面で使われます。

* 値を順番に生成したい
* 大量データを少しずつ処理したい
* イテレーターを自作したい
* 処理を途中で止めたり再開したりしたい

ただし、通常のWeb開発では、関数宣言・関数式・アロー関数・async関数ほど頻繁には使いません。

ライブラリやフレームワークの内部、または特殊なデータ処理で使われることが多いです。

---

# 10. コンストラクター関数

コンストラクター関数は、オブジェクトを作るための関数です。

```js
function User(name, age) {
  this.name = name;
  this.age = age;
}

const user = new User("田中", 25);

console.log(user);
```

出力結果です。

```txt
User { name: "田中", age: 25 }
```

`new` を付けて呼び出すことで、新しいオブジェクトを作れます。

## コンストラクター関数の特徴

コンストラクター関数では、慣習的に関数名を大文字で始めます。

```js
function User(name) {
  this.name = name;
}
```

そして、`new` を使って呼び出します。

```js
const user = new User("田中");
```

このとき、JavaScript内部では新しいオブジェクトが作られ、そのオブジェクトに対して `this` が紐づきます。

## 現在はclass構文を使うことが多い

現在のJavaScriptでは、コンストラクター関数よりも `class` 構文を使うことが多いです。

```js
class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  greet() {
    console.log(`${this.name}さん、こんにちは`);
  }
}

const user = new User("田中", 25);

user.greet();
```

ただし、`class` も内部的にはプロトタイプベースの仕組みの上に成り立っています。

## コンストラクター関数の使いどころ

現在の実務では、新しくコンストラクター関数を書く機会は少なめです。

ただし、次のような理由で理解しておく価値があります。

* 古いJavaScriptコードを読むため
* `this` や `new` の挙動を理解するため
* `class` の内部構造を理解するため
* プロトタイプを理解するため

新しくコードを書く場合は、基本的には `class` を使う方が読みやすいです。

---

# 11. 再帰関数

再帰関数とは、自分自身を呼び出す関数です。

```js
function countdown(number) {
  console.log(number);

  if (number <= 0) {
    return;
  }

  countdown(number - 1);
}

countdown(3);
```

出力結果です。

```txt
3
2
1
0
```

`countdown` 関数の中で、もう一度 `countdown` を呼び出しています。

## 再帰関数の使いどころ

再帰関数は、階層構造のデータを扱うときに便利です。

たとえば、メニューやコメントのツリー構造です。

```js
const menu = {
  name: "root",
  children: [
    {
      name: "settings",
      children: [
        { name: "profile", children: [] },
        { name: "security", children: [] },
      ],
    },
    {
      name: "help",
      children: [],
    },
  ],
};

function printMenu(item) {
  console.log(item.name);

  for (const child of item.children) {
    printMenu(child);
  }
}

printMenu(menu);
```

再帰関数は、次のような場面で使われます。

* ツリー構造のデータを処理する
* ネストした配列やオブジェクトを処理する
* 階層メニューを処理する
* フォルダ構造を処理する

## 再帰関数の注意点

再帰関数では、終了条件がとても重要です。

```js
function loop() {
  loop();
}

loop();
```

このように終了条件がないと、無限に呼び出されてエラーになります。

そのため、再帰関数を書くときは、必ず「どこで止まるのか」を明確にする必要があります。

# 12. 純粋関数

純粋関数は、同じ入力に対して必ず同じ出力を返す関数です。

また、関数の外側に影響を与えません。

```js
function add(a, b) {
  return a + b;
}
```

`add(1, 2)` は、何度呼び出しても必ず `3` を返します。

```js
console.log(add(1, 2));
console.log(add(1, 2));
console.log(add(1, 2));
```

すべて `3` です。

## 純粋関数ではない例

次の関数は、純粋関数ではありません。

```js
let count = 0;

function increment() {
  count++;
  return count;
}
```

この関数は、外側の `count` を変更しています。

また、呼び出すたびに結果が変わります。

```js
console.log(increment());
console.log(increment());
console.log(increment());
```

```txt
1
2
3
```

## 純粋関数の使いどころ

純粋関数は、予測しやすくテストしやすいです。

```js
function calculateTaxIncludedPrice(price, taxRate) {
  return price * (1 + taxRate);
}

console.log(calculateTaxIncludedPrice(1000, 0.1));
```

同じ引数を渡せば、必ず同じ結果になります。

そのため、次のような処理に向いています。

* 計算処理
* データ変換
* バリデーション
* フォーマット処理
* テストしやすくしたい処理

ReactやAngularなどのフロントエンド開発でも、純粋関数を意識すると、状態管理やテストがしやすくなります。

---

# 13. 無名関数

無名関数とは、名前を持たない関数です。

```js
const greet = function () {
  console.log("こんにちは");
};
```

この `function () {}` の部分には名前がありません。

そのため、無名関数です。

アロー関数も、多くの場合は無名関数として使われます。

```js
const greet = () => {
  console.log("こんにちは");
};
```

## 無名関数の使いどころ

無名関数は、その場限りの処理に向いています。

```js
setTimeout(function () {
  console.log("1秒後に実行");
}, 1000);
```

アロー関数で書くと次のようになります。

```js
setTimeout(() => {
  console.log("1秒後に実行");
}, 1000);
```

イベント処理や配列操作でもよく使われます。

```js
const numbers = [1, 2, 3];

const doubled = numbers.map(function (number) {
  return number * 2;
});
```

ただし、複雑な処理を無名関数で書くと、何をしている処理なのか分かりにくくなります。

```js
button.addEventListener("click", () => {
  // 何十行も処理が続く
});
```

このような場合は、名前付き関数に切り出した方が読みやすくなります。

```js
function handleClick() {
  console.log("クリックされました");
}

button.addEventListener("click", handleClick);
```

# 14. どの関数を使えばいいのか

JavaScriptには多くの関数の書き方があります。

最初は、どれを使えばいいのか迷いやすいです。

基本的には、次のように考えると整理しやすいです。

| 種類         | 主な用途               |
| ---------- | ------------------ |
| 関数宣言       | 名前のある基本的な処理を書く     |
| 関数式        | 関数を変数として扱う         |
| 即時関数       | 一度だけ実行したい処理を書く     |
| アロー関数      | 短い処理やコールバックを書く     |
| メソッド       | オブジェクトに関連する処理を書く   |
| コールバック関数   | あとで実行する処理を渡す       |
| 高階関数       | 処理の一部を差し替えられるようにする |
| async関数    | 非同期処理を読みやすく書く      |
| ジェネレーター関数  | 値を順番に生成する          |
| コンストラクター関数 | オブジェクトを生成する        |
| 再帰関数       | 階層構造を処理する          |
| 純粋関数       | 予測しやすい計算や変換を書く     |
| 無名関数       | その場限りの短い処理を書く      |

## 実務でよく使う優先度

実務でよく使うのは、主に次の関数です。

```txt
関数宣言
関数式
アロー関数
メソッド
コールバック関数
高階関数
async関数
```

即時関数は、昔ほど頻繁には使われません。

ただし、古いコードや小さな初期化処理では今でも見かけます。

ジェネレーター関数やコンストラクター関数は、毎日使うものではありませんが、JavaScriptの理解を深めるうえでは知っておくと役立ちます。

# 15. 初心者におすすめの使い分け

初心者のうちは、まず次のように使い分けるとよいです。

## 通常の処理は関数宣言

```js
function calculateTotal(price, quantity) {
  return price * quantity;
}
```

処理に名前を付けたい場合は、関数宣言が読みやすいです。

## 短い処理はアロー関数

```js
const doubled = numbers.map((number) => number * 2);
```

配列操作やコールバックでは、アロー関数が便利です。

## 一度だけ実行する初期化処理は即時関数

```js
(() => {
  const theme = localStorage.getItem("theme") || "light";

  document.body.dataset.theme = theme;
})();
```

再利用しない初期化処理で、変数を外に出したくない場合に使えます。

## 非同期処理はasync関数

```js
async function fetchUsers() {
  const response = await fetch("/api/users");
  const users = await response.json();

  return users;
}
```

API通信では、`async` / `await` を使うと読みやすくなります。

## オブジェクトの処理はメソッド

```js
const user = {
  name: "田中",
  greet() {
    console.log(`${this.name}さん、こんにちは`);
  },
};
```

データと処理をまとめたい場合は、メソッドが向いています。

# まとめ

JavaScriptには、さまざまな関数の書き方があります。

最初は多く見えるかもしれませんが、それぞれの役割を整理すると理解しやすくなります。

まず押さえたいのは、次の関数です。

* 関数宣言
* 関数式
* 即時関数
* アロー関数
* メソッド
* コールバック関数
* 高階関数
* async関数

関数宣言は、基本的な処理を名前付きで定義したいときに使います。

関数式は、関数を値として扱いたいときに使います。

即時関数は、一度だけ実行したい処理や、変数を外に出したくない処理に使います。

アロー関数は、短い処理やコールバック関数を書くときに便利です。

メソッドは、オブジェクトに関連する処理をまとめるときに使います。

コールバック関数や高階関数を理解すると、JavaScriptらしい柔軟な書き方ができるようになります。

async関数を理解すると、API通信などの非同期処理を読みやすく書けるようになります。

大切なのは、すべてを暗記することではありません。

「この処理は再利用したいのか」
「一度だけ実行したいのか」
「あとで呼び出したいのか」
「非同期処理なのか」
「短く書いた方が読みやすいのか」

このように、目的から関数の種類を選べるようになることが大切です。
