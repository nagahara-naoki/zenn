JavaScript には、関数宣言、関数式、アロー関数、コールバック、高階関数など、多くの用語があります。

混乱しやすい理由は、これらが同じ分類ではないからです。

- 関数宣言・関数式・アロー関数は、主に**書き方**の違い
- コールバック・高階関数・再帰関数は、主に**役割**の違い
- 純粋関数は、関数が持つ**性質**の違い

この記事では、この3つの軸を分けて整理します。

## 最初に結論

普段の開発では、まず次の判断ができれば十分です。

| やりたいこと | 選びやすい書き方 |
| --- | --- |
| 名前のある処理を定義する | 関数宣言 |
| 関数を変数や引数として扱う | 関数式・アロー関数 |
| オブジェクト自身を `this` で参照する | メソッド構文 |
| 短いコールバックを書く | アロー関数 |
| 非同期処理を書く | `async` 関数 |

どの書き方が常に優れている、という話ではありません。特にアロー関数は通常の関数と `this` の扱いが異なります。

## 関数宣言

関数宣言は、`function` の後ろに名前を書く形式です。

```js
function calculateTax(price, rate) {
  return price * rate;
}

console.log(calculateTax(1_000, 0.1)); // 100
```

関数宣言には、次の特徴があります。

- 名前が必須
- 宣言を含むスコープで束縛が事前に作られる
- 定義より前から呼び出せる

```js
console.log(double(4)); // 8

function double(value) {
  return value * 2;
}
```

「コードが上へ移動する」のではなく、JavaScript がコードを評価する前に関数の束縛を初期化する、と捉える方が正確です。

処理の入口や、ファイル内の主要な処理に名前を付けたいときに向いています。

## 関数式

関数式は、関数を値として作り、変数などへ代入する形式です。

```js
const calculateTax = function (price, rate) {
  return price * rate;
};
```

JavaScript の関数は値なので、配列へ入れたり、引数として渡したり、戻り値として返したりできます。

```js
const operations = [
  (value) => value + 1,
  (value) => value * 2,
];

console.log(operations[1](5)); // 10
```

`const` で定義した関数式は、変数が初期化される前には呼び出せません。

```js
greet(); // ReferenceError

const greet = function () {
  console.log("こんにちは");
};
```

このエラーは「関数式だから」ではなく、`const greet` が初期化前だから発生します。

## アロー関数

アロー関数は、関数式を簡潔に書くための構文です。

```js
const double = (value) => value * 2;
```

オブジェクトを1行で返す場合は、オブジェクトを丸括弧で囲みます。

```js
const createUser = (name) => ({ name });

console.log(createUser("Taro")); // { name: "Taro" }
```

### アロー関数は `this` を作らない

アロー関数は、呼び出し方によって決まる独自の `this` を持ちません。外側のレキシカル環境から `this` を参照します。

そのため、次のようなオブジェクトメソッドには通常のメソッド構文が適しています。

```js
const user = {
  name: "Taro",
  greet() {
    console.log(`こんにちは、${this.name}です`);
  },
};

user.greet();
```

次の書き方では、`this` は `user` を指しません。

```js
const user = {
  name: "Taro",
  greet: () => {
    console.log(this.name);
  },
};
```

また、アロー関数は `new` で呼び出せず、独自の `arguments` も持ちません。短いから選ぶのではなく、この意味の違いを理解して選びます。

## メソッド

オブジェクトのプロパティとして呼び出す関数を、一般にメソッドと呼びます。

```js
const cart = {
  items: [1_000, 2_000],
  total() {
    return this.items.reduce((sum, price) => sum + price, 0);
  },
};

console.log(cart.total()); // 3000
```

メソッドを変数へ取り出すと、呼び出し元のオブジェクト情報は失われます。

```js
const total = cart.total;
total(); // this.items を参照できずエラー
```

必要なら、オブジェクト経由で呼ぶか、`bind` で `this` を固定します。

```js
const boundTotal = cart.total.bind(cart);
console.log(boundTotal()); // 3000
```

## コールバック関数

別の関数へ渡し、後から呼び出してもらう関数がコールバックです。これは構文ではなく役割の名前です。

```js
const prices = [100, 200, 300];
const taxedPrices = prices.map((price) => price * 1.1);
```

ここでは、`(price) => price * 1.1` がコールバックです。通常の関数式でも書けます。

```js
const addTax = function (price) {
  return price * 1.1;
};

const taxedPrices = prices.map(addTax);
```

複雑なコールバックは名前を付けて外へ出すと、処理の意図とテスト対象が明確になります。

## 高階関数

関数を引数に受け取るか、関数を返す関数を高階関数と呼びます。

```js
function withLogging(operation) {
  return (...args) => {
    console.log("start", args);
    const result = operation(...args);
    console.log("end", result);
    return result;
  };
}

const add = (a, b) => a + b;
const loggedAdd = withLogging(add);

loggedAdd(2, 3);
```

`map`、`filter`、`reduce` も、コールバックを受け取る高階関数です。

高階関数は共通処理を分離するのに役立ちますが、関数を何層も重ねると実行順序が追いにくくなります。「重複を減らせるか」だけでなく「呼び出しを読めるか」も判断基準にします。

## async関数

`async` 関数は、常に Promise を返します。

```js
async function getUserName(id) {
  const response = await fetch(`/api/users/${id}`);

  if (!response.ok) {
    throw new Error(`ユーザー取得に失敗しました: ${response.status}`);
  }

  const user = await response.json();
  return user.name;
}
```

`return "Taro"` と書いても、呼び出し側が受け取るのは `Promise<string>` です。

```js
const namePromise = getUserName(1);
```

結果を使う側でも `await` するか、`then` を使います。

## ジェネレーター関数

ジェネレーター関数は `function*` で定義し、値を必要なタイミングで順番に生成します。

```js
function* createIds() {
  let id = 1;

  while (true) {
    yield id;
    id += 1;
  }
}

const ids = createIds();
console.log(ids.next().value); // 1
console.log(ids.next().value); // 2
```

反復処理を独自に表現したい場合に便利ですが、通常の配列処理で十分なら無理に使う必要はありません。

## 即時関数や再帰関数は何を表すのか

即時関数（IIFE）は「定義と同時に呼び出す形」です。

```js
(() => {
  const privateValue = "外から参照しない値";
  console.log(privateValue);
})();
```

ES Modulesが普及した現在は、グローバル変数を避ける目的だけでIIFEを使う場面は減っています。

再帰関数は「自分自身を呼び出す役割」を持つ関数です。関数宣言でも関数式でも書けます。つまり、どちらも関数宣言やアロー関数と並ぶ別の構文分類ではありません。

## 純粋関数

純粋関数は、同じ入力に対して同じ結果を返し、外部の状態を変更しない関数です。

```js
function calculateTotal(items) {
  return items.reduce((sum, item) => sum + item.price, 0);
}
```

純粋関数はテストしやすく、処理を予測しやすいという利点があります。一方、画面表示、通信、ログ出力などの副作用はアプリケーションに必要です。すべてを純粋にするのではなく、計算部分と副作用を分離するのが現実的です。

## 実務での選び方

迷ったときは、次の順番で考えます。

1. オブジェクト自身を `this` で扱うならメソッド構文
2. 短いコールバックならアロー関数
3. 名前のある主要処理なら関数宣言
4. 関数を条件によって差し替えるなら関数式
5. 非同期処理なら `async` を付け、戻り値がPromiseであることを型や名前で示す

プロジェクト内では、個人の好みよりも一貫性を優先します。

## よくあるミス

### `map` に async関数を渡した結果を待たない

```js
const userPromises = ids.map(async (id) => fetchUser(id));
const users = await Promise.all(userPromises);
```

`map` 自体は Promise の完了を待ちません。結果は Promise の配列になるため、並列に待つなら `Promise.all` を使います。

### 省略returnでオブジェクトを返せていない

```js
const incorrect = (name) => { name };
const correct = (name) => ({ name });
```

波括弧は関数本体として解釈されるため、オブジェクトリテラルを丸括弧で囲みます。

## まとめ

JavaScriptの関数を整理するときは、用語を同じ階層へ並べないことが重要です。

- 関数宣言・関数式・アロー関数は書き方
- コールバック・高階関数・再帰関数は役割
- 純粋関数は性質
- `async` とジェネレーターは実行モデルを変える構文

まず「`this` が必要か」「値として渡すか」「非同期か」を判断すると、適切な書き方を選びやすくなります。
