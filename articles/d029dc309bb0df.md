`new` は、コンストラクターを使ってオブジェクトを生成する演算子です。

```js
class User {
  constructor(name) {
    this.name = name;
  }
}

const user = new User("Taro");
```

この記事では、`new User("Taro")` の裏で何が起きるかに範囲を絞ります。

## まず結論

通常のコンストラクター関数を `new` で呼ぶ流れは、概念的に次のように整理できます。

1. 新しいオブジェクトを作る
2. その `[[Prototype]]` をコンストラクターの `prototype` へつなぐ
3. 新しいオブジェクトを `this` としてコンストラクター本体を実行する
4. コンストラクターが別オブジェクトを返さなければ、新しいオブジェクトを結果にする

```text
new User("Taro")
  ├─ objectを作る
  ├─ object.[[Prototype]] = User.prototype
  ├─ Userをobjectをthisとして実行
  └─ objectを返す
```

これは理解用の要約です。class fields、継承、Proxyなどを含む実際の仕様手順は、さらに細かく定義されています。

## コンストラクター関数で確認する

```js
function User(name) {
  this.name = name;
}

User.prototype.greet = function () {
  return `Hello, ${this.name}`;
};

const user = new User("Taro");

console.log(user.name); // Taro
console.log(user.greet()); // Hello, Taro
console.log(Object.getPrototypeOf(user) === User.prototype); // true
```

`name` は生成された `user` 自身が持ち、`greet` は `User.prototype` から見つかります。

## classでも基本関係は同じ

```ts
class User {
  constructor(public name: string) {}

  greet(): string {
    return `Hello, ${this.name}`;
  }
}

const user = new User("Taro");
```

classの通常メソッドもprototypeに置かれます。

```js
console.log(Object.getPrototypeOf(user) === User.prototype);
console.log(user.greet === User.prototype.greet);
```

ただしclassは、単なる見た目の置き換えではありません。class constructorは `new` なしでは呼べず、class本体はstrict modeで評価されるなど、通常の関数との違いがあります。

## newできる値とできない値

`new` の右辺は、内部メソッド `[[Construct]]` を持つ必要があります。

```js
function NormalFunction() {}
class Example {}

new NormalFunction();
new Example();
```

アロー関数やメソッド構文で作った関数はconstructableではありません。

```js
const Arrow = () => {};

new Arrow(); // TypeError: Arrow is not a constructor
```

`typeof value === "function"` だけでは、`new` できるかを完全には判断できません。

## 戻り値の特別な規則

基底クラスや通常のコンストラクター関数がオブジェクトを明示的に返すと、そのオブジェクトが `new` 式の結果になります。

```js
function User(name) {
  this.name = name;

  return {
    name: "Override",
  };
}

const user = new User("Taro");
console.log(user.name); // Override
```

プリミティブ値を返した場合は通常無視され、生成したオブジェクトが返ります。

```js
function User(name) {
  this.name = name;
  return 100;
}

const user = new User("Taro");
console.log(user.name); // Taro
```

constructorから別オブジェクトを返す設計は、型やprototypeの関係を予想しにくくします。生成方法を切り替えたいなら、static factory methodなどの方が意図を表しやすいことがあります。

## extendsとsuper

派生クラスでは、`super()` が基底クラスのconstructorを呼び、`this` を利用可能にします。

```ts
class Animal {
  constructor(public name: string) {}
}

class Dog extends Animal {
  constructor(
    name: string,
    public breed: string,
  ) {
    super(name);
  }
}
```

派生クラスのconstructorで `super()` より前に `this` を使うとエラーになります。

```ts
class Dog extends Animal {
  constructor(name: string) {
    // this.name = name; // ReferenceError
    super(name);
  }
}
```

基底クラスでは新しい `this` を用意してconstructorを進めますが、派生クラスでは `super()` の結果として `this` が初期化されるためです。

## new.target

`new.target` は、関数やconstructorが `new` 経由で呼ばれたか、どのコンストラクターが起点かを確認するメタプロパティです。

```js
function User(name) {
  if (!new.target) {
    throw new TypeError("User must be called with new");
  }

  this.name = name;
}
```

classは `new` なしで呼ぶと自動的にエラーになるため、この防御コードは主に従来のコンストラクター関数で使われます。

継承では、基底クラス内の `new.target` も実際に `new` された派生クラスを指します。

## Reflect.construct

`Reflect.construct` は、`new` に近い内部操作を関数として利用できます。

```js
const user = Reflect.construct(User, ["Taro"]);
```

通常の生成では `new` の方が読みやすいですが、メタプログラミングで引数配列や別のnew targetを扱う場合に使われます。

## TypeScriptでの役割

TypeScriptはconstructorの引数や生成後のインスタンス型を検査します。

```ts
class User {
  constructor(
    public name: string,
    public age: number,
  ) {}
}

const user = new User("Taro", 20);
```

型情報はJavaScriptへ変換すると消えます。`new` の実行時セマンティクス自体はJavaScriptのものです。

## newを使わない生成との比較

単純なデータなら、factory functionで十分なこともあります。

```js
function createUser(name) {
  return {
    name,
    greet() {
      return `Hello, ${name}`;
    },
  };
}
```

`new` を使うかどうかは好みだけでなく、次を基準にします。

- prototypeメソッドを共有したいか
- `instanceof` やclass継承が設計に必要か
- private fieldなどclassの機能を使いたいか
- 単純な値オブジェクトで十分か

## まとめ

- `new` はconstructableな値に対して使う
- 生成オブジェクトはconstructorの `prototype` へつながる
- constructor本体では生成中のオブジェクトを `this` として扱う
- オブジェクトを明示的に返すと、生成結果を置き換える
- 派生クラスの `this` は `super()` によって初期化される
- 単純な生成ならfactory functionも比較する
